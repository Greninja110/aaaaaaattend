    File Format Instructions
    Required Columns:
    • roll_number: Student roll number
    • student_name: Student name (for reference)
    • date: Date in YYYY-MM-DD format
    • status: Either "present" or "absent"
    Important Notes:
    • Do not modify roll numbers or student names
    • Date format must be YYYY-MM-DD (e.g., 2024-03-15)
    • Status must be exactly "present" or "absent"
    • Empty rows will be ignored
    • Duplicate entries will overwrite previous ones
    Sample CSV Format:
    roll_number,student_name,date,status
    CE21001,John Doe,2024-03-15,present
    CE21002,Jane Smith,2024-03-15,absent
    CE21003,Bob Johnson,2024-03-15,present
