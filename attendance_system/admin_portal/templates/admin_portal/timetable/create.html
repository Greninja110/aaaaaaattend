Help & Tips
Tips:
  • Ensure no time conflicts with existing entries

  • Faculty Subject assignment must exist
  • End time must be after start time

  • Room conflicts will be automatically checked
Check for Conflicts

When creating a timetable entry, the system will automatically check for:

  • Faculty conflicts: Same faculty at same time
  • Room conflicts: Same room at same time
  • Class conflicts: Same class at same time
